## 🚀 Cómo Ejecutar
1. Abrir `index.html` en el navegador.  
2. Seleccionar un ejercicio del menú.  
3. Abrir la **consola** (`F12 → Consola`) para ver los resultados.  

También se pueden ejecutar los `.js` desde Node.js:

```bash
node ejercicio1/ejercicio1.js
```

(Sustituye el número según corresponda)
