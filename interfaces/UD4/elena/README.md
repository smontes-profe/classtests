Por qué son compatibles:

- No imponen copyleft (ShareAlike), por lo que podemos elegir CC BY-NC-SA sin conflictos

# Escenario hipotético: ¿Y si una imagen fuera CC BY-SA?

Si una sola imagen utilizada en la galería tuviera licencia:

- Creative Commons BY-SA

Entonces automáticamente estaría obligado a que TODO el proyecto se licencie bajo:

- CC BY-SA

Motivo:

La cláusula ShareAlike obliga a que cualquier obra derivada que incluya ese recurso preserve exactamente la misma licencia sin añadir limitaciones como el uso no comercial

Por tanto:

- La landing page completa se convertiría en una obra derivada

- Se contagiaría la obligación de usar CC BY-SA

- No podría añadir restricciones adicionales (como NC)

# Conclusión

- La licencia que hemos elegido (CC BY-NC-SA) es totalmente compatible con los recursos utilizados (Pexels, Pixabay, Freepik)

- Si hubiera un recurso CC BY-SA, toda la web tendría que cambiar a CC BY-SA

- La página incluye créditos completos para cumplir con todos los requisitos de atribución
