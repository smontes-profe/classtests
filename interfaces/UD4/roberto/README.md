# Miarma Portfolio

Este es el portafolio del proyecto Miarma, una artista digital ficticia especializada en paisajes de ciencia ficción.

## Estructura

- `index.html`: Página principal (Landing Page).
- `credits.html`: Página de créditos y licencias.
- `assets/`: Recursos estáticos (imágenes, video, audio, estilos, scripts).

## Herramientas Utilizadas

- **VS Code**: Editor de código.
- **Google Gemini**: Generación de imágenes y asistencia en código.
- **HTML5/CSS3/JS**: Tecnologías web estándar.

## Justificación de Formatos Técnicos

- **WebP (Hero Image)**: Se eligió WebP para la imagen principal por su excelente relación calidad/compresión, permitiendo una carga rápida sin sacrificar detalle visual.
- **SVG (Logo)**: El formato vectorial asegura que el logo se vea nítido en cualquier resolución y tamaño de pantalla.
- **JPG (Galería)**: Se usó JPG para las imágenes de la galería ya que es un estándar compatible y eficiente para fotografías complejas.
- **MP4 (Video)**: H.264/MP4 es el estándar más compatible para video en la web.
- **MP3 (Audio)**: Formato universalmente soportado para audio comprimido.

## Licencia de Tu Obra (Landing Page)

### Licencia Elegida
**CC BY-NC 4.0 (Atribución-NoComercial 4.0 Internacional)**
He elegido esta licencia porque permite a otros compartir y adaptar mi trabajo siempre que me den crédito y no lo usen con fines comerciales. Considero que es adecuado para un portafolio educativo/personal.

### Análisis de Compatibilidad
Los recursos utilizados son o bien de generación propia (Logo, código) o generados por IA (que generalmente no tienen copyright restrictivo o son de uso libre para este contexto), lo que me permite licenciar la obra derivada bajo CC BY-NC sin conflictos. Si hubiera usado recursos con licencias "ShareAlike" (SA), estaría obligado a usar la misma licencia.

### Escenario Hipotético
**Pregunta:** "Si una de las imágenes de la galería hubiera tenido una licencia Creative Commons Atribución-CompartirIgual (CC BY-SA), ¿qué licencia estarías obligado a usar para tu landing page? ¿Por qué?"

**Respuesta:** Si hubiera utilizado una imagen con licencia **CC BY-SA**, estaría obligado a licenciar mi obra derivada (la landing page) también bajo **CC BY-SA** (o una compatible). Esto se debe a la cláusula "ShareAlike" (CompartirIgual), que exige que las obras derivadas se distribuyan bajo la misma licencia que la obra original.
