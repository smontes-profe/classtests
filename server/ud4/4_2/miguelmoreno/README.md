
Actividad que implementa un sistema en **PHP** para la **gestión de usuarios y empleados** con conexión a base de datos.  
Incluye funcionalidades como registro, inicio de sesión, edición y eliminación de registros.


## Archivos principales
- **`conexion.php`**  
  Configuración y creación de la conexión a la base de datos.

- **`config.php`**  
  Parámetros del sistema.

- **`login.php` / `logout.php`**  
  Inicio y cierre de sesión de los usuarios.

- **`registrar_usuario.php` / `nuevo_usuario.php`**  
  Registro de nuevos usuarios en el sistema.

- **`listar_usuario.php` / `editar_usuario.php` / `eliminar_usuario.php`**  
  Implementan el CRUD (Crear, Leer, Actualizar, Eliminar) de usuarios.

- **`listar_empleados.php` / `buscar_empleado.php` / `eliminar_empleado.php` / `eempleado.php`**  
  Implementan el CRUD de empleados, incluyendo búsqueda y edición.

- **`lista.php`**  
  Muestra listados generales de datos (usuarios o empleados).

- **`sesion_usuarios` / `sesion2_empleados.php`**  
  Scripts para manejar sesiones activas de usuarios y empleados.


## Requisitos
- **Servidor local**: XAMPP, WAMP o similar  
- **PHP**: versión 7.4 o superior  
- **Base de datos**: MySQL o MariaDB  
- **Navegador web**: para acceder a las páginas PHP
